Fluent-Qt is maintained as an open-source project. Community support is best
effort and does not have a guaranteed response time.

## Choose the right channel

- **Installation, integration, and usage questions:** use
  [Discussions Q&A](https://github.com/calvinhxx/Fluent-Qt/discussions/categories/q-a).
- **Reproducible incorrect behavior:** open the structured
  [bug report](https://github.com/calvinhxx/Fluent-Qt/issues/new?template=bug_report.yml).
- **Early product or API ideas:** start in
  [Ideas](https://github.com/calvinhxx/Fluent-Qt/discussions/categories/ideas).
  Use the feature request form after the user outcome and reusable scope are
  clear.
- **Applications and migration experiences:** share them in
  [Show and tell](https://github.com/calvinhxx/Fluent-Qt/discussions/categories/show-and-tell).
- **Security-sensitive reports:** follow [SECURITY.md](SECURITY.md). Do not post
  vulnerability details in Issues or Discussions.

When asking for help, include the FluentQt version or commit, C++ or PySide6
surface, Qt/Python version, operating system, architecture, install route, and
the smallest relevant code or Gallery route. Redact credentials, customer data,
private repository links, and local paths first.

Maintainers may move or close duplicate, incomplete, out-of-scope, or
security-sensitive public reports while pointing to the appropriate channel.
