# Fluent-Qt community

## Public entry points

- [Q&A](https://github.com/calvinhxx/Fluent-Qt/discussions/categories/q-a)
  for installation, integration, API, PySide6, packaging, and WebAssembly help.
- [Ideas](https://github.com/calvinhxx/Fluent-Qt/discussions/categories/ideas)
  for exploring a real application scenario before filing a scoped feature
  request.
- [Show and tell](https://github.com/calvinhxx/Fluent-Qt/discussions/categories/show-and-tell)
  for applications, experiments, screenshots, and migration lessons.
- [Bug report](https://github.com/calvinhxx/Fluent-Qt/issues/new?template=bug_report.yml)
  for reproducible incorrect behavior.
- [Contributing](../../CONTRIBUTING.md), [support](../../SUPPORT.md),
  [security](../../SECURITY.md), and the [Code of Conduct](../../CODE_OF_CONDUCT.md)
  define the participation boundaries.

Do not publish credentials, customer data, private repository links, or
security vulnerability details in Issues or Discussions.
