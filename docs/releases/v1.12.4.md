## C++ SDK

The installed SDK resolves its public headers from the include root. Projects
that link `FluentQt::FluentQt` can keep their existing CMake setup. The release
includes a vcpkg overlay for the static Widgets library. Download the overlay
from the release assets and pass its directory to `--overlay-ports`.

Window caption buttons retain their hover and press feedback when the window
is inactive.

## Page Studio and Qt Designer

Page Studio supports nine interface languages and adds device monitoring,
AI workbench and serial console templates. The template picker supports
keyboard navigation, and undo restores the previous page.

Date and time fields retain empty or explicit selections across the schematic
preview, WebAssembly and exported forms. Editing a control updates the affected
preview without rebuilding unrelated inputs. C++, PySide6 and Qt Designer
exports preserve DataGrid sample rows and Accordion sections, including a
Label placed directly inside an Accordion. Exported pages inherit the host
application's accent color.
