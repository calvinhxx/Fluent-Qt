Fluent-Qt 1.11.1 adds range selection and image viewing, makes the desktop
Gallery easier to navigate and scale, and corrects text alignment, popup
captures, and painting at small display scales. C++ and PySide6 Gallery include
matching examples for the new controls.

## Select ranges and inspect images

`RangeSlider` selects a lower and upper value with two thumbs. It supports
horizontal and vertical layouts, a minimum interval, keyboard steps, value
tips, and committing changes continuously or when dragging ends. Its track and
thumbs share the existing `Slider` rendering, and both values are exposed to
accessibility clients.

`ImageViewer` displays a caller-provided image with pointer-centered zoom,
dragging, pinch input, keyboard navigation, and optional zoom controls. Fit
modes keep the whole image visible or leave small images at their original
size. Images can be inspected inside `FlipView`; input passes to the parent
when the viewer cannot pan further on that axis. Thumbnail rendering reuses
cached image data.

## Scale and search the Gallery

Desktop Gallery supports saved interface zoom from 50% to 200%, including
67%. Use Ctrl/Cmd with `+`, `-`, or `0`, the zoom indicator, or the command
palette. Zoom resizes the content's logical layout while preserving the native
window frame. Saved window placement accounts for the scale it was recorded
at, including maximized-window restoration. Default 100% preserves existing
saved placement.

Fractional and sub-100% display scales no longer leave stale white lines or
undersized image caches. Repairs retain local paint regions, and GPU-only
frames do not force a full-window widget repaint. Native title-bar positioning
and hit testing account for the effective scale.

Component and example search returns cancellable, paged results and ignores
obsolete requests. Shared window commands expose shortcuts consistently;
opening the zoom bubble preserves the active editor's focus. Browser Gallery
search also updates accessibility geometry as results change.

## Consistent text, menus, and overlays

Compact controls share text-positioning rules, including shaped fallback
fonts, while editable fields keep text clear of their trailing buttons.
Menu icons and checkmarks align with their content inset. `SelectorBar`
preserves selection and keyboard focus when items move into overflow.

Dialog and popup background captures preserve widget positions and effect
bounds, including shadows. Switching from a native translucent background to
an opaque one completes correctly at low effective device pixel ratios.

## Breaking build change: desktop Gallery prerequisites

Building the C++ or PySide6 desktop Gallery now requires the private development
headers matching the selected Qt installation. These files provide the window
and repaint interfaces needed for correct live zoom and local painting.
Configuration stops with installation guidance if they are missing, instead
of selecting a full-window repaint fallback.

On Debian or Ubuntu, install `qtbase5-private-dev` for Qt 5 or
`qt6-base-private-dev` for Qt 6 alongside the matching Qt packages. For other
SDKs, install the private headers for that exact Qt kit. A library-only build
can disable `FLUENT_QT_BUILD_GALLERY` and `FLUENT_QT_BUILD_PYSIDE6_GALLERY`.
The base Widgets library does not acquire this requirement. See the
[build workflow](../development/build-workflow.md).

C++17 and Qt Widgets 5.15+ or 6.2+ remain supported on Windows, macOS, and
Linux. The browser Gallery continues to use browser scaling; desktop process
zoom is not exposed there. Native consumers should rebuild with their matching
Qt and toolchain; a stable C++ binary ABI is not promised.

## Documentation and developer workflow

The documentation sidebar groups components and extension guides by topic,
and live examples size themselves to their content. Release history replaces
the former public roadmap. Preview generation handles UTF-8 consistently.
Incremental Python binding generation preserves unchanged outputs, and the
local WSL validation helper reuses a Linux-native workspace.
