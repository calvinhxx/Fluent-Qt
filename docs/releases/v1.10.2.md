# Fluent-Qt 1.10.2

Fluent-Qt 1.10.2 adds searchable commands, coordinated form validation, and
reusable code snippets. Popup, dialog, and drawer backgrounds now share
configurable effects and modal input behavior across C++, PySide6, and
WebAssembly.

## Search application commands

`CommandPalette` searches by command name, group, and keywords. It reuses the
same `QAction` objects as menus and toolbars, including their shortcuts,
enabled state, and checked state. Keyboard navigation selects a result;
activation restores the previous focus before executing the command.

Gallery includes grouped application commands and an editing example that
keeps Copy, Cut, and Select All connected to the editor. The compact panel
adapts to its results and the available window size.

## Consistent modal surfaces

`Popup`, `Dialog`, and `DrawerView` share configurable backdrop blur and
dimming. These effects remain independent of modality: a modal surface blocks
background clicks and shortcuts, including Gallery navigation, while keeping
keyboard focus inside the active surface.

Each component's Gallery page demonstrates its effect settings and dismissal
options. High Contrast suppresses blur, and transitions follow the motion
setting. Nested surfaces close in order. Calendar triggers toggle once per
click, including the Start and End calendars inside `DateTimeRangePicker`.
Inside a dialog, Escape resets a chart's zoom before closing the dialog.

## Form validation and feedback

`FormController` coordinates existing `Field` widgets, tracking edits,
interaction, validation, and submission without taking ownership of editor
values. It supports delayed validation, rejects stale results after an edit,
and focuses the first invalid field when submission fails.

The connection-settings example demonstrates local and delayed validation,
save failures, and retry. Fields show one feedback message at a time and keep
compact spacing when the surrounding layout grows.

## Reusable code blocks

`CodeBlock` displays selectable source with C++, Python, and QML syntax
colors, folding, wrapping, and a configurable visible-line limit. Copying
preserves the original source, including tabs and line endings. Browser
clipboard operations report whether the copy succeeded.

Gallery source panels now use this shared component. C++, Python, and browser
examples demonstrate the same selection, copy, and scrolling behavior.
