Fluent-Qt 1.10.3 adds tools for editing values, configuring charts, and working
with larger collections. The website now brings live component examples,
C++ and PySide6 code, and API reference together in English and Chinese.

## Edit values and configure charts

`NumberBox` supports dragging to adjust a value, alongside precise text entry.
A drag has a clear commit point and can be cancelled without losing the
starting value. Applications can choose the range, step, and sensitivity.

`PropertyPanel` groups editable fields, searches properties, and restores
defaults. It adapts its labels and editors to the available width and keeps
application data under the caller's control. Gallery includes a chart
configuration workbench to try these interactions together.

Chart views can save PNG images, export original model rows as CSV, and copy
images or data. Exports distinguish the current range from all data and
preserve gaps in the source model. Image exports omit temporary pointer and
focus decoration.

## Search and select structured data

`AutoSuggestBox` supports asynchronous suggestions, cancellation, and rejection
of stale results. Composition input and popup placement have been refined.

`TagInput` provides identity-based tags with keyboard editing and explicit
remove buttons. `TreeSelect` adds model-backed hierarchical selection.
Multi-select popups keep their selection and scrolling state during updates.

## Work with tables and adaptive panes

`DataGrid` adds optional pinned columns while preserving editing, keyboard
traversal, and selection behavior. `DataGridToolBar` combines search, filters,
and column controls. `ListDetailView` retains content and focus when switching
between a side-by-side layout and a compact detail pane.

Selection and accessibility work in large lists is bounded more carefully.
Gallery uses Toast for completed actions while keeping persistent values and
selection summaries visible beside their controls.

## Read and try components in one place

The website has a searchable documentation directory, foundation guides, and
component pages with live examples, C++ and PySide6 snippets, and public API
members. Example themes are local to the preview and do not change the website
theme. Static captures remain available while an example loads or if it fails.

SpatialView and SpatialItem documents open in 3D and provide local mode
controls. Homepage and document examples recover from loading failures, and
updated browser assets no longer reuse an older program from the cache.

## More reliable focus, rendering, and compatibility

CheckBox, RadioButton, ComboBox, RatingControl, HyperlinkButton, and Slider
have clearer keyboard focus and more reliable painted bounds in compact
layouts and at fractional display scales. Radio-button selection feedback
keeps the surrounding layout stable.

Spatial surfaces refresh when embedded widgets repaint, and Gallery reduces
repeated composition and glyph-rendering work. Browser accessibility and
dialog stacking have been corrected. Qt 5 property initialization, native
editor sizing, and Windows window setup also receive compatibility fixes.

The supported desktop baselines remain Qt 5.15+ and Qt 6.2+, with the pinned
Qt 6.9.3 WebAssembly build and the matching PySide6 distributions.
