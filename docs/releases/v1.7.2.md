Fluent-Qt 1.7.2 adds a native multi-select input, shortens the path from a
repository to a working desktop window, and improves cross-platform behavior.

## Components and behavior

- `MultiSelectComboBox` provides filtering, select-all, keyboard navigation,
  accessibility, C++ and PySide6 APIs, and Gallery examples without changing
  the existing single-select `ComboBox`.
- DatePicker and TimePicker now inherit application fonts consistently and
  align their flyout content across supported Qt versions.
- Disabled ListView rows ignore pointer selection, dropdown chevrons mirror in
  right-to-left layouts, and NavigationView keeps its layered content mask in
  translucent windows.
- Cross-platform picker and ColorPicker warnings have been removed without
  changing their public behavior.

## Onboarding and AI-assisted development

- `fluentqt doctor`, `fluentqt create`, and `fluentqt trial` check the local Qt
  toolchain, generate C++ or PySide6 projects, and exercise the first real
  window without overwriting an existing directory.
- The generated workbench starter separates its responsive shell from the
  replaceable product page and validates both wide and minimum-size layouts.
- The read-only Inspector reports layout, input, text, and accessibility
  findings for a built application; it does not rewrite the interface.
- The installable GUI Skill now includes sealed cross-agent evidence, stricter
  visual review, and the maintained workbench structure. The website also
  publishes a searchable API Explorer.

## Delivery and compatibility

- Full PySide6 matrix validation is restored, and release candidates are built
  before tagging so standard releases promote verified desktop packages and
  the same 18-wheel Python bundle to TestPyPI and PyPI.
- The compatibility policy now states the public API, deprecation, Qt support,
  and C++ ABI boundaries used from the 1.7 line onward.

There are no breaking runtime API changes in this patch release.
