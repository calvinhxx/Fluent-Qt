Fluent-Qt 1.6.3 makes it easier to turn existing or new projects into polished
desktop applications, while improving default collection and text-input
behavior and strengthening package integration.

## AI-assisted GUI development

- The cross-agent `build-fluentqt-gui` Skill provides one evidence-based
  workflow for Codex, Claude Code, Cursor, GitHub Copilot, and other compatible
  agents. It supports libraries, CLIs, TUIs, services, plugins, and greenfield
  projects without assuming an existing interface.
- A generated component catalog connects public C++ and PySide6 APIs to Gallery
  samples, focused tests, integration patterns, and intent-based queries.
- Theme, component-selection, density, alignment, responsive-layout, input
  method, overlay, and visual-review gates use the shipped Gallery as the
  quality benchmark instead of treating the first compiling window as done.
- The Skill, catalog, schemas, query tools, and deterministic evaluations ship
  with development and source packages, with CI checks preventing stale or
  incomplete assets.

## Component quality

- `ListView` now provides a Fluent default delegate for ordinary text and icon
  rows, including measured separation between the selection indicator and row
  content across supported design languages.
- `TextEdit` hides its placeholder during input-method preedit, preventing
  placeholder text from painting underneath composed input.

## Build and package integration

- Installed Apple packages resolve CoreGraphics and Objective-C dependencies on
  the consuming machine instead of exporting build-machine SDK paths.
- MSVC targets now inherit the caller or vcpkg triplet's CRT linkage selection
  rather than forcing dynamic CRT linkage.

## Compatibility

- The native C++ baseline remains C++17 with Qt 5.15+ or Qt 6.2+.
- PySide6 remains optional and continues to support Python 3.10+ with the
  documented Qt/PySide/Shiboken alignment requirements.
- The release contains no intentional breaking public API changes.
