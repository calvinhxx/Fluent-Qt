Fluent-Qt 1.11.2 fixes Windows window handling in headless Qt applications and
adds disabled states to the Gallery's two-state checkbox example.

## Headless windows on Windows

Qt's `offscreen` and `minimal` platform plugins assign synthetic window IDs.
Fluent-Qt now skips native window styling, system backdrops, and native title-bar
operations for those windows. This keeps a synthetic ID out of Win32 window APIs
when a test creates and shows a widget. The native Windows and Direct2D backends
continue to use real window handles. [Issue #116](https://github.com/calvinhxx/Fluent-Qt/issues/116)

## Gallery and project website

The C++ and PySide6 Gallery examples show disabled checked and unchecked boxes
alongside the interactive checkbox. The displayed sample code includes both
disabled states.

The project website now offers Ko-fi alongside WeChat Pay and Alipay. The English
homepage opens on Ko-fi, the Chinese homepage opens on WeChat Pay, and links to
a specific CNY amount still select the matching QR code.

## Build and release validation

WebAssembly browser checks share one Gallery build and run in parallel. Release
validation also shares stable-ABI wheels across compatible Python versions and
leaves selected duplicate packaging jobs to the release candidate on release
pushes to the main branch.
