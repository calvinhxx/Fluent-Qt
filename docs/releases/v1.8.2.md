Fluent-Qt 1.8.2 adds custom theme tokens for applications and individual
components, makes custom ComboBox fonts work throughout the dropdown, and
fixes callback, navigation, and slider behavior across supported Qt versions.

## Custom themes and fonts

- `UserTheme::applyOverrides()` customizes global colors, corner radii, and
  fonts without editing a theme file. Individual components can use
  `setThemeOverrides()` to override selected tokens while unspecified fields
  continue following the global theme. Invalid configurations are rejected
  without changing the current state. Matching helpers are available in
  PySide6; see [Custom themes](../design-languages/custom-themes.md).
- Local overrides remain attached to the configured component across theme
  changes. They do not automatically propagate to child components. Local
  font scaling replaces the global scale; explicit widget fonts keep priority.
- ComboBox now applies `setFont()` to the field, editor, and dropdown, including
  a dropdown that is already open. Rows grow to fit larger text, and selecting
  a font role restores theme-managed typography.
- Nested StackContentHost widgets preserve their parent's painted surface
  under translucent window backdrops, including locally themed previews.

## Component and Gallery fixes

- Dialog handles synchronous closure during `open()` without entering an
  event loop that can no longer finish. ToggleButton handles reentrant state
  changes and synchronous destruction from its supported notification paths,
  including on Qt 5.15 and Qt 6.2.
- Slider and ScrollBar handle full integer ranges and follow Qt's orientation,
  right-to-left, and inverted-appearance settings. Slider tick rendering also
  handles automatic intervals and large ranges.
- Removing a tab before the selected tab now notifies listeners of the changed
  selected index. DropDownButton painting no longer changes its interaction
  state or emits state-change signals.
- Gallery coach marks are released with their owning preview. Sample code
  preserves callback lifetimes, and slider and coach-mark controls have
  accessible names.

The Qt and C++ baselines are unchanged. Inherited Qt button setters and button
group callbacks retain Qt's lifetime rules; on older Qt versions, use
`deleteLater()` when deleting a button from those callbacks.

## Website

The bilingual website refreshes its Gallery screenshots and sharing artwork.
Hero particles respond to pointer interaction while preserving pause controls,
reduced-motion preferences, high-contrast behavior, and bounded animation work.
