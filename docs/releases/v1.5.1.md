Fluent-Qt 1.5.1 expands the public widget set with reusable layout,
notification, identity, and icon building blocks, making more of the
Gallery-grade experience available directly to applications.

## New public controls

- The new `<FluentQt/Layout.h>` category exposes Card, Divider, Expander, and
  Accordion. Applications can compose token-backed surfaces, DPI-aligned
  separators, animated disclosure content, and single- or multiple-expansion
  groups with explicit content ownership.
- FontIcon provides theme-aware bundled glyphs with optical-size selection,
  custom color, and rotation. CompoundButton adds a secondary description while
  preserving the existing Button interaction contract.
- Avatar supports images, Unicode-safe initials, shape and size presets, and
  optional presence status. Toast provides in-window notifications with
  severity styling, layout-direction-aware edge placement, animation, and
  bounded stacking.

## Gallery and integration

- Gallery navigation, settings feedback, code blocks, and sample surfaces now
  reuse the same public Fluent controls available to applications.
- New Gallery cards demonstrate the added controls with dedicated assets and
  focused source snippets, while installed-header integration checks cover the
  expanded category entry points.

## Fixes

- Popup now republishes its Fluent surface color after a theme change so
  composed controls consistently resolve the active layer color.
