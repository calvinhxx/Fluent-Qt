# Fluent-Qt 1.8.3

Fluent-Qt 1.8.3 brings reusable particle backgrounds and branded startup
screens to C++ and PySide6 applications. It also improves keyboard selection,
text editing, and source-code reading and copying in the Gallery.

## Particle backgrounds without a new graphics dependency

- `ParticleBackdrop` provides flowing ribbons, floating dots, and a starfield
  through one CPU-painted QWidget component. Applications can compose normal
  child controls over it and configure speed, density, frame rate, pointer
  interaction, background transparency, and edge fades.
- The default budget is 240 particles at up to 30 frames per second. Hidden
  or fully clipped surfaces stop continuous animation; reduced-motion and
  high-contrast preferences are respected. The component adds no OpenGL
  dependency.
- Gallery includes three examples with matching C++ and Python source. Its
  home banner selects an effect at startup while excluding the previous
  displayed effect. The default-on **Home particle effects** setting takes
  effect immediately and persists across launches. A disabled launch keeps
  the previous effect history.

## Reusable startup screens

- `SplashScreen` covers an application's chosen content area with artwork,
  optional title and subtitle, status text, and progress. Branded presentation
  reveals the application identity; Simple presentation uses a centered icon
  and loading ring.
- Applications own loading work and call `dismiss()` when ready. Reaching
  100% does not close the screen automatically. An optional icon target
  connects the branded dismissal to the application's title bar, with motion
  adapted to the user's preference.
- Both Gallery applications now use the public component for startup, and
  the Status & info sample lets users replay either presentation.

## More reliable interaction and code examples

- ComboBox dropdowns support keyboard navigation and Enter activation, emit
  activation notifications for user selection, and handle callbacks that
  change or destroy the control. Disabled and empty controls stay closed.
- TextEdit restores a tall caret after automatic height adjustment, including
  when fallback fonts are used, while preserving ordinary manual scrolling.
- Gallery code examples wrap in narrow windows. Keyboard and context-menu
  copying use the original source, preserving tabs and Unicode characters
  instead of copying display-only wrapping characters.
- The browser Gallery restores its accessible widget tree and prevents HTML
  accessibility proxies from appearing through the rendered interface.
- The installable GUI Skill keeps its workflows reachable through focused
  references, including onboarding links inside the standalone archive.
  Design descriptions accept concise non-empty constraint lists while
  retaining concept selection and visual-evidence requirements.

The C++17 and supported Qt baselines are unchanged. The new components and
their PySide6 exports are additive.
