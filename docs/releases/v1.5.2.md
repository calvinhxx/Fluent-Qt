Fluent-Qt 1.5.2 adds reusable command surfaces and a shared editing-command
layer, while strengthening notification lifecycles and same-window overlay
reliability.

## Command and editing surfaces

- CommandBar provides ordered primary and secondary actions, responsive
  overflow, optional inline labels, and caller-owned QAction integration.
- CommandBarFlyout provides contextual primary and secondary commands with
  standard or transient opening, widget or point anchoring, and collapsed or
  expanded presentation.
- EditingCommandRouter exposes stable window-scoped actions for undo, redo,
  cut, copy, paste, delete, and select all. It follows the focused Fluent text
  editor and keeps command availability synchronized with selection, history,
  read-only state, and clipboard content.
- Fluent text controls now share the same editing-menu behavior, and the
  Gallery includes focused examples for the new command surfaces.

## Notifications

- Toast now supports caller-owned actions, hover-paused timeouts, keyed
  in-place updates, bounded stacking, dismissal reasons, and lifecycle signals.
- Accessibility announcements use a centralized compatibility path across the
  supported Qt versions.
- Gallery notification examples cover actions, updates, queue eviction,
  placement, and lifecycle status without overloading individual sample cards.

## Reliability and build quality

- Reentrant destruction and synchronous callbacks are guarded across StackView,
  transient overlays, command presenters, and borrowed command teardown.
- Expander preserves its layout-height notification order so Gallery sample
  chrome remains stable while still allowing synchronous receiver destruction.
- Warning-enabled builds are clean, MSVC compilation serializes PDB writes, and
  contract coverage includes the expanded editing and notification surfaces.
