# Fluent-Qt 1.10.1

Fluent-Qt 1.10.1 improves command menus, text logging, and Gallery rendering.
Command bars can reuse nested menus, while the ordinary command examples
remain the starting point in the C++, Python, and browser Galleries.

## Command menus

- `CommandBar` and `CommandBarFlyout` now accept actions with attached
  `FluentMenu` hierarchies, including primary, overflow, and secondary commands.
  Shared actions retain their checked state and remain owned by the application.
- Nested menus keep their rows aligned, respect right-to-left layout, and
  adjust at screen edges. Moving the pointer across overlapping menu shadows
  no longer dismisses the open submenu. Escape returns one level at a time;
  choosing a leaf command closes the menu chain.
- Command menus use a consistent surface with lighter shadows. Their scroll
  content no longer adds an extra background, and mouse interaction does not
  display a keyboard focus outline. Keyboard navigation retains its focus cue.
- Separate Gallery examples demonstrate three menu levels and shared choices.

## Append plain text

`TextEdit::appendPlainText()` appends literal text as a new paragraph, including
when the editor is read-only. It preserves the selection and undo history and
follows new content only when the reader was already at the bottom. Empty-text
behavior follows `QPlainTextEdit`. A new activity-log example demonstrates
appending and clearing entries in all three Galleries.

## Clearer controls and previews

- Unchecked check boxes and radio buttons have more visible outlines in Light
  and Dark themes. Hover strengthens the outline; High Contrast retains its
  full outline opacity.
- Angled 3D panels use clearer text sampling, and the Gallery avoids redundant
  panel captures when content has not changed.
- Gallery cards keep neighboring examples aligned as previews resize and
  source-code sections expand. C++ and Python use the same layout behavior.
- Python intro-tour cleanup avoids stale event filters when widgets are
  destroyed.
