# Fluent-Qt 1.8.5

> **Status:** Historical release note

Fluent-Qt 1.8.5 adds charts and file controls for C++ and PySide6 applications,
refines Toast notifications, and makes the Gallery's startup handoff smoother.

## Charts with shared models

The new Charts module includes `LineChart`, `AreaChart`, `BarChart`,
`HorizontalBarChart`, `PieChart`, `DonutChart`, `ScatterChart`, and `Sparkline`,
alongside a configurable `ChartView`. It uses Qt Widgets without adding Qt
Charts or another plotting dependency.

Applications retain ownership of `ChartModel` data and can share one model
between several views. Indexed data, bounded drawing work, cached projections,
and batched updates support large datasets and streaming. Hidden charts stop
scheduling frames. Large data preparation can run separately from the view.

Charts include keyboard navigation, theme-aware colors, and hover readouts that
wrap long names and close when the pointer leaves the data. The Gallery provides
matching C++ and Python examples for each chart type.

## File selection and progress

`FileDropZone` provides a drop target and a browse action. `FileListView` shows
file names, supporting text, progress, and optional remove or retry actions
from a caller-owned model. Long names wrap, and rows are drawn without creating
a widget for every file.

The controls emit requests; the application decides how to validate, read,
upload, retry, or remove files. The Gallery demonstrates these interactions on
desktop and browser builds. Browser selection accepts one file at a time;
desktop selection supports multiple files.

## Refined notifications

Toast uses a compact neutral card, a semantic status marker, a stronger shadow,
and smoother entry and stack movement. Detailed messages and action captions
wrap within the available width. An optional small close button sits in the
top trailing corner; closing it reports `DismissReason::CloseButton`.

Existing `showToast` calls remain valid. Notifications remain non-closable by
default and preserve pointer pass-through when no interactive option is enabled.
Buttons with explicit line breaks now measure their full caption correctly.

## Smoother Gallery startup

The C++ and PySide6 Galleries prepare hidden page layouts during loading and
reuse the rendered content during the SplashScreen's exit. Decorative particle
animations pause and resume with that handoff, reducing stalls as progress
reaches 100% and the logo moves into the title bar. Reduced and disabled motion
preferences remain respected.

The supported Qt baselines are unchanged. This release also fixes generation
of the new chart bindings with PySide6 6.2.
