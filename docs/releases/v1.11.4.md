Fluent-Qt 1.11.4 adds diagnostic reports and native Windows 11 Snap Layouts.
Gallery can prepare a report for a GitHub issue from a button beside Settings.

## Component library

`DiagnosticSession` records recent UI events, environment details and widget
snapshots, then packages them as an in-memory ZIP. It is available in C++ through
`<FluentQt/Diagnostics.h>` and in Python as `fluentqt.DiagnosticSession`.
Applications decide where to save reports and how to share them.

On Windows 11, hovering over a resizable `Window`'s maximize button can open the
system Snap Layouts menu. Windows controls the available layouts and whether
the menu is enabled. Fixed-size and full-screen windows do not offer this target.

`LineEdit`, `AutoSuggestBox`, `NumberBox`, `PasswordBox` and `TagInput` now share
the same frame settings. The unfocused underline defaults to zero width, and
the focused underline remains 2 pixels wide. Explicit border widths and frame
visibility still apply. Setting an underline width to zero no longer paints a
hairline.

`Toast` handles owned action widgets safely and keeps its content within narrow
windows.

## Gallery

Desktop C++ and Python Gallery retain recent diagnostics while running. The
**Report a problem** button prepares a ZIP containing environment details,
recent events, logs and any matching system crash reports already on disk.
It copies the file to the clipboard and shows a notification. Choose
**Open GitHub issue** there, then paste the attachment and describe the problem.
WebAssembly downloads the ZIP for attachment instead.

Gallery does not generate crash dumps or upload reports automatically. Log and
crash-file contents may include private information; review the ZIP before
sharing it publicly. Failed exports offer a retry without opening an issue.
