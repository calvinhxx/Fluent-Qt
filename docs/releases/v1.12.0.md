Version 1.12.0 brings live property previews to the component documentation
and offline release notes to Gallery.

## Try a component and copy its code

Open **Property preview** on a component page to edit a live Qt example in
the browser. The editor shows the resulting C++ and PySide6 code for the
selected settings. The 99 component pages include previews for particle
effects, Spatial and QML hosting.

## Gallery updates

Open **What’s new** in the Gallery title bar to read the changes included in
the installed version. In narrow windows the entry becomes a megaphone icon.
The history is bundled with Gallery and can be read offline.

The TreeView example demonstrates model column labels above the first row.
Gallery previews also account for frame borders when sizing the example.

## Changes for application developers

- `Button::IconAbove` and `Button::IconBelow` place the icon above or below
  the label. The first icon selects the icon-before-text layout when the
  application has not selected a layout explicitly.
- `TreeView` reserves room for visible column headers. When the caption and
  column headers are both hidden, `headerlessTopInset` sets the gap before
  the first row. The default is two logical pixels.
- On Windows, restoring a maximized window uses the destination monitor’s
  work area to position its content.
- Overflowed menu-bar actions remain reachable. Collection views honor
  standard item-model roles and per-item selection behavior, and scrolling
  recovers correctly when the user reverses direction or takes over the
  scrollbar.
