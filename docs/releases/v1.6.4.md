Fluent-Qt 1.6.4 makes generated desktop interfaces more dependable and turns
the WebAssembly Gallery into a bilingual C++ and Python learning surface,
while correcting custom text-editor spacing.

## Bilingual WebAssembly Gallery

- Browser component pages can switch both the Use reference and every Source
  block between native C++ and PySide6 teaching code. The installed C++ and
  PySide6 Galleries remain focused on their own runtime language.
- Python examples are generated from the tested, native-equivalent PySide6
  sample catalog. A component page enables bilingual documentation only when
  every displayed sample has a matching Python source, preventing mixed or
  incomplete pages.
- Language selection stays synchronized across the page, with Python-aware
  highlighting, copy behavior, and dynamic code-block measurement. The browser
  still runs the C++ WebAssembly previews and does not embed a Python runtime.

## AI-assisted GUI quality

- The `build-fluentqt-gui` workflow now scales its evidence requirements to the
  size of the application while keeping visual quality, model/view architecture,
  performance, and transient-lifecycle checks together.
- Product-reference patterns and experience-differentiation guidance help
  generated applications choose structures and components that fit the task
  instead of repeating one generic shell.
- Visual-evidence manifests, expanded retrieval and composition evaluations,
  and CI validation make density, alignment, clipping, state coverage, lazy
  construction, and bounded-memory behavior explicit acceptance criteria.

## Text input

- `TextEdit` now honors custom content margins when positioning text,
  placeholders, and caret rows, and recalculates its dynamic height when margin,
  font, or theme metrics change.

## Compatibility

- The native C++ baseline remains C++17 with Qt 5.15+ or Qt 6.2+.
- PySide6 remains optional and continues to support Python 3.10+ with the
  documented Qt/PySide/Shiboken alignment requirements.
- The release contains no intentional breaking public API changes.
