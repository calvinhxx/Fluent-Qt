Fluent-Qt 1.5.0 makes the library easier to integrate into production
applications with explicit public contracts, application-owned localization,
more predictable cross-platform behavior, and faster large-view rendering.

## Public APIs and integration

- New category entry headers such as `<FluentQt/BasicInput.h>`,
  `<FluentQt/Collections.h>`, and `<FluentQt/TextFields.h>` let applications
  include only the component families they use while the complete
  `<FluentQt/FluentQt.h>` entry remains supported.
- Typography roles and collection selection modes now use shared strongly typed
  enums, replacing stringly typed and per-view variants with APIs that are
  easier to discover and validate at compile time.
- ScrollView, DrawerView, and StackView expose explicit borrowed, reparented,
  and owned widget lifetimes so applications can choose how hosted content is
  released.
- Same-window overlays share one lifecycle coordinator, keeping modal input,
  scrims, ownership, and close behavior consistent across dialogs and popups.

## Localization, accessibility, and RTL

- DatePicker and TimePicker let applications provide field placeholders and
  accessible names for picker actions while staying synchronized with inherited
  Qt locale changes.
- ToggleSwitch labels, icon-only actions, and window caption-button accessible
  names are application-owned instead of silently falling back to English.
- Input and navigation controls provide more complete keyboard focus,
  right-to-left interaction, and accessible state feedback. PipsPager uses a
  language-neutral automatic description and preserves application overrides.

## Reliability and performance

- Theme changes are applied transactionally so registered Fluent elements
  observe one coherent update instead of intermediate palette states.
- AnchorLayout resolves dependent anchors deterministically, including cyclic
  graphs, while date and time controls keep locale-dependent state coherent.
- Dynamic design tokens are centralized, FlowView bounds paint, hit-test, and
  drag work to the visible viewport, and ProgressBar reuses animation timing
  instead of rebuilding it on each frame.
- Gallery acceptance now exercises every component route across Light and Dark
  themes, RTL, disabled states, and representative display scales, alongside
  source, FetchContent, and installed-package integration probes.

## Breaking changes

- Replace string font roles with `Typography::FontRole` values, for example
  `Typography::FontRole::Body`.
- Replace `FlowSelectionMode`, `GridSelectionMode`, `ListSelectionMode`, and
  `TreeSelectionMode` with `fluent::collections::SelectionMode`.
- Review hosted-widget calls and select the appropriate
  `fluent::WidgetOwnership` policy where ownership is now explicit.
- Include supported public entry headers rather than implementation-only
  compatibility headers, which are no longer installed.
- Supply localized picker placeholders, picker action names, ToggleSwitch
  labels, and icon-only accessible names where an application previously relied
  on English defaults.
