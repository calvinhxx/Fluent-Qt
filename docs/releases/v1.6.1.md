Fluent-Qt 1.6.1 completes the public presentation of the Python compatibility
release. It does not change component behavior or the Python API introduced in
1.6.0.

## Python package pages

- `FluentQt` and `FluentQt-Gallery` now publish complete GitHub-flavored
  Markdown descriptions instead of blank PyPI project pages.
- Both distributions expose documentation, repository, issue, changelog, and
  homepage links together with platform, Python, and license metadata.
- The release-bundle gate rejects missing descriptions, project links,
  classifiers, or license metadata before TestPyPI and PyPI publication.

## Project presentation

- The README, website, and GitHub repository description now surface optional
  PySide6 compatibility while keeping the native C++ Qt Widgets library as the
  primary project.
- Hosted-widget ownership naming and the stable-tag publication boundary are
  documented explicitly for maintainers and contributors.

## Release validation

- The Gallery rapid-route scrolling check now waits for the existing smooth
  wheel animation instead of requiring a synchronous scrollbar jump.
