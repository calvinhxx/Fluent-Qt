# Fluent-Qt 1.10.0

Fluent-Qt 1.10.0 adds date and time range selection, application QML hosting,
and tools for editing live previews. Optional extension modules share a
common lifecycle across C++, Python, and WebAssembly applications.

## Date and time ranges

- `DateTimeRangePicker` combines a range calendar, independently optional
  start and end values, inline time editing, and whole-day presets in one
  compact entry. Endpoint dates use small anchored flyouts; selecting a
  range keeps the panel open until **Done** or a light-dismiss action.
- The range picker preserves time zones and the end-of-day value when using
  coarser minute increments. It supports localized labels and date formats,
  keyboard input, and accessible range validation.
- `CalendarView` scrolls continuously through date, month, and year rows.
  Trackpad input follows the gesture, while mouse-wheel input uses a short
  transition. Header arrows and Page Up/Down retain page navigation.

## QML pages and optional extensions

- QmlBridge embeds application QML pages in Widgets windows, with shared
  application data and Fluent theme settings. Gallery examples cover loading,
  theme changes, actions, errors, and unloading in C++, Python, and the browser.
- The optional Plugins module manages extension dependencies, activation,
  and cleanup. Spatial and QmlBridge offer session helpers while preserving
  application-owned widgets and models. Their additional dependencies remain
  separate from the core Widgets library.
- QMLPlus gains computed bindings, conditional state, motion, and anchor
  helpers for composing Widgets interfaces, with focused Gallery examples.

## Live preview tools

- Python Live Scene previews reload in the same window while retaining user
  input and selection. Local preview commands and MCP tools support inspecting
  the scene, interacting with controls, and capturing the result.
- The optional region editor lets a scene author register editable values,
  select a region, preview source changes, and compare actual before/after
  screenshots. Changes can be kept, reverted, or undone; revision checks
  protect intervening source edits. Enable it with `--edit`.

## Interaction and rendering fixes

Button layout spacing and TreeView selection indicators behave consistently
when controls are resized or reselected. Spatial and QML previews also receive
fixes for renderer transitions, resource cleanup, input mapping, and fallback
to a usable 2D view across supported platforms.
