You can build forms visually in Qt Designer or design a page in the web
Page Studio and export it to C++, PySide6 or a Qt Designer `.ui` file.

## Designer and Page Studio

- Qt Creator and PySide6 Designer can open the same FluentQt forms. With all
  optional modules installed, the Widget Box has 95 entries and the New Form
  dialog has four templates. The Designer tools are included in the source archive.
- Page Studio provides editable templates, a live Qt preview, shareable layouts
  and optional AI-assisted editing. Exports include the controls and layouts.

## Widgets and Gallery

- `NumberBox` accepts empty values by default. Call `setEmptyAllowed(false)`
  to restore the last number when a blank or invalid edit is committed.
  Select `SpinButtonPlacementMode::Split` to place minus and plus on opposite
  sides of the value.
- Temporary widget cursors now restore the application’s cursor after drag,
  resize and color-pick interactions. Oversized `CoachMark` cards stay anchored
  within the space their host can provide.
- Desktop Gallery installers and the Python wheels include QmlBridge.
  The installed galleries now show all 99 entries, including `QmlView`.
