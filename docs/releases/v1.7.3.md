Fluent-Qt 1.7.3 adds a faster Gallery UI preview loop and polishes several
controls across Light and Dark themes.

## Gallery development

- Live Scene keeps a PySide6 preview window open and updates the selected scene
  after each save, so layout and style changes can be checked without restarting
  the full Gallery.
- Native preview renders the compiled C++ SampleCard for a selected route and
  sample, with theme, layout direction, size, snapshot, and Inspector report
  options.
- Normal Gallery startup and the public FluentQt component APIs are unchanged.

## Components and behavior

- CalendarView month and year selection indicators now use rounded Fluent
  outlines.
- DatePicker and TimePicker wheel flyouts align with their fields more
  consistently.
- TeachingTip shadows now spread evenly around the outline.
- Connected TabView tabs, separators, and content surfaces now form a cleaner
  continuous shape.

## Delivery

- Release-candidate preparation and release-only Python validation now avoid
  repeated work while keeping the full package matrix and artifact checks.

There are no breaking runtime API changes in this patch release.
