## DataGrid

Custom headers that paint only labels or controls now have a solid background
when the grid is shown in a dialog. To change the color of the built-in
headers, call `setHeaderBackground(color)`. The color also applies to pinned
headers and the corner where row and column headers meet. Sorting and column
resizing remain available. Call `resetHeaderBackground()` to follow the theme
again. These APIs are available in C++ and PySide6.

## Application starters

Generate an operations monitor with KPI cards, a latency chart and a filterable
table. The example uses local sample data and keeps the data source separate
from the UI.

```bash
python3 tools/onboarding/fluentqt create my-monitor --language cpp --starter monitor
python3 tools/onboarding/fluentqt create my-py-monitor --language pyside6 --starter monitor
```

Generated PySide6 projects also accept Python 3.10 when used with a compatible
FluentQt source build. Published wheels keep their existing Python requirements.
