Fluent-Qt 1.9.2 adds reusable Timeline and Stepper controls and improves
Gallery clarity at different display scales. C++, Python and WebAssembly
Gallery examples share the new controls and their presentation.

## Timeline and Stepper

Timeline displays application-defined sequences with titles, descriptions,
timestamps, icons and status markers. It borrows a caller-owned item model
and supports leading, trailing and alternating node alignment. Its item-view
foundation preserves the existing Fluent scrolling and selection behavior.

Stepper presents horizontal or vertical steps with independently controlled
completion and error states. Activating a step requests navigation; the
application decides whether to change the current step. Both controls reuse
Fluent theme, accessibility and motion behavior.

The Gallery includes interactive examples and matching source for both
controls. They are available through the C++ and PySide6 public APIs.

## Clearer Gallery images and text

Gallery component cards now render SVG artwork at the actual display
resolution. They retain detail on high-density screens and in the 3D panel
cache. Reused documents and rendered images are cached to reduce work during
page changes and scrolling. Every card has a maintained SVG master and a
matching PNG export.

Text crossing a cached panel boundary keeps its original shaping and pixel
coverage, including fractional display scales and Qt 5.15. Glyph scratch
images stay within their memory budget, and oversized fonts use Qt's direct
rendering path. These fixes also apply to the Python Gallery.

The Calendar example consistently opens its demonstrated month, so its
selected date remains visible throughout the year.

## Website and package delivery

The project site offers an interactive Spatial example and updated native
Gallery imagery. The embedded example loads on request and pauses while
hidden.

Gallery installers and Python wheels include the SVG artwork and rendering
dependencies. Release checks cover their contents and architecture across
the existing Windows, Linux and macOS package matrix.

Upgrade both Python packages together:

```bash
python -m pip install --upgrade "FluentQt==1.9.2" "FluentQt-Gallery==1.9.2"
python -m fluentqt_gallery
```
