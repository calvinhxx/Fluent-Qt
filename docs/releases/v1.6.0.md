Fluent-Qt 1.6.0 adds a release-grade PySide6 distribution while keeping the
existing C++ library and Qt 5.15 path available by default.

## PySide6 UILib

- The optional Shiboken6 binding exposes the planned FluentQt component
  surface through one native `_fluentqt` module, preserving Qt object identity,
  signals, properties, virtual dispatch, themes, and process-wide resources.
- Python-facing hosted-widget APIs use explicit owned, borrowed, and reparented
  contracts, with lifecycle and garbage-collection coverage for views,
  navigation, overlays, menus, models, delegates, and native windows.
- Typed package facades, generated stubs, an API manifest, and deprecation
  policy make accidental symbol loss or incompatible API drift a CI failure.
- The Qt 6.2.4 plus CPython 3.10 source/build baseline remains a blocking
  Linux and Windows x64 compatibility gate. Official first-release wheels use
  matched Qt/PySide6/Shiboken6 6.9.3 and CPython 3.11–3.13 across Windows,
  Linux, and macOS x64/ARM64, with Linux ARM64 starting at CPython 3.12.

## Standalone Python Gallery

- `FluentQt-Gallery` is a separate pure-Python distribution that pins the exact
  matching `FluentQt` version and consumes only public package APIs.
- Its 88 routes and 199 live SampleCards mirror the native Gallery catalog,
  with compact Python teaching snippets, responsive layouts, isolated settings,
  single-instance behavior, and platform window integration.
- Keeping the Gallery out of the core wheel leaves the reusable UILib focused
  while providing an installable cross-platform integration application.

## Distribution integrity

- Full CI builds 17 native wheels, repairs and audits all five Linux wheels,
  verifies clean installations, and reduces byte-identical Gallery outputs to
  one universal wheel.
- A canonical 18-wheel bundle records the source commit, originating CI run,
  file hashes, and manylinux evidence. TestPyPI and PyPI publication reuse this
  exact bundle without rebuilding.
- The dedicated publishing workflow uses OIDC Trusted Publishing, deployment
  approval, package-index hash verification, public clean-install smoke tests,
  and attestations instead of long-lived PyPI credentials.

## C++ reliability

- Hosted-widget and navigation containers now expose clearer lifetime paths
  while retaining the legacy owned defaults and caller-transfer behavior.
- Input, model/view, overlay, menu, scrolling, and window teardown paths are
  hardened against reentrancy, deferred deletion, and stale borrowed objects.
- ToggleButton preserves tri-state values, command surfaces separate primary
  and secondary activation, and ComboBox keeps hierarchical model state and an
  open dropdown synchronized.
