# Fluent-Qt 1.11.3

> **Status:** Release note

Fluent-Qt 1.11.3 adds unit labels and custom trailing controls to text fields,
a searchable dual-list selector, and a caret-anchored completion example.
It also fixes editable ComboBox geometry and makes Gallery input examples more
consistent across supported Qt versions.

## Text fields with trailing content

LineEdit and ComboBox can display suffixes such as `px` and `pt` without adding
them to the edited value. Applications can instead host a custom trailing
widget with explicit ownership. The shared trailing slot keeps text, native
buttons and custom controls apart in both layout directions.

Editable ComboBox fields retain their text area after changing selections,
updating model data or accepting a popup choice. This fixes text shifting back
to Qt's native editor rectangle. [Issue #125](https://github.com/calvinhxx/Fluent-Qt/issues/125)
NumberBox's drag indicator is vertically centered at integer and fractional
display scales.

The input examples show these options together with refined field borders and
focus states. Read-only fields retain an underline, and dark-theme focus keeps
the field surface. Existing custom text margins remain caller-owned.

## Searchable dual-list selection

The new Transfer control lets users search either list and move selected items
between them with directional buttons. It respects disabled items and keeps the
caller's source model unchanged, storing selection through stable keys. The
Gallery demonstrates choosing a project team in both C++ and PySide6.

## Completion near the text caret

TextEdit exposes its caret rectangle and a change signal so applications can
position their own completion surfaces. The new Gallery example offers member
suggestions after `@`, keeps editing focus in the text field, and supports arrow
navigation, insertion and undo. Query parsing and suggestion data remain
application-owned.

The shared editing-command example now keeps TextEdit's default height
animation when lines are added or removed.

## Gallery and compatibility

Component examples share the same framed preview and source-code presentation.
The editable ComboBox, trailing-content fields and asynchronous-search examples
keep their responsive layouts within that common frame.

Gallery painting preserves redirected clipping on older Qt versions, and
PySide6 trailing-widget validation avoids unnecessary thread wrappers. The live
preview client also tolerates transient reads without replaying an edit.

## Build and release workflow

Compiler caches, grouped test executables and precompiled Python binding headers
reduce repeated build work. Release validation retains its existing checks while
sharing candidate artifacts, and a paired benchmark workflow measures build and
relink changes on the same runner.

These additions preserve the existing public APIs. Applications using new
headers or bindings should rebuild against 1.11.3 with their matching Qt toolchain.
