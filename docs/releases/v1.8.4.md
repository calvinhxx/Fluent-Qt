Fluent-Qt 1.8.4 reduces the rendering work of startup screens and refreshes the
Gallery's application icon, installers, and website images.

## Lighter startup rendering

`SplashScreen` reuses its background and reflection images, repaints only the
regions that change during the reveal animation, and avoids laying out its
contents again for numeric progress updates. Its appearance, startup timing,
dismissal behavior, and accessibility preferences remain unchanged.

## Updated Gallery identity

- The desktop and PySide6 Gallery applications, browser Gallery, and website
  share the refreshed application icon. macOS keeps the source image resolution
  for sharper Dock rendering on Retina displays.
- Native Gallery previews initialize the application icon before opening their
  windows, so previews use the same icon as the full application.
- Windows installer artwork and the macOS disk image use the refreshed branding.
  The disk image aligns the application and Applications icons with the install
  arrow.

## Current Gallery screenshots

The English and Chinese websites and READMEs now show native Windows Gallery
captures, including light and dark views with the Mica window background.
Component previews and social-sharing images have been refreshed to match.

The public C++ and PySide6 APIs and supported Qt baselines are unchanged.
