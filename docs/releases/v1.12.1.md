The website now offers nine languages. You can open a component’s API reference
and adjust its live example in the language you selected.

## Application changes

- Large `PropertyPanel` forms create editors as their rows approach the visible
  area. Tab navigation, search and explicit editor access can also bring a row
  into use. Accessing the form controller still prepares every field for validation.
- `AreaChart` can reuse the series fill while the pointer moves across the plot.
  Hover readings continue to update over the fill.
- `ImageViewer` releases cached scaled images when hidden. Looking up an icon
  by name no longer requires loading the full icon catalog.
- Projects using the CMake target with Qt 5 and MSVC inherit the UTF-8 compiler
  option for C++ sources that include FluentQt headers.

## Gallery

The **What’s new** dialog keeps its header and footer dividers opaque while you
scroll the release notes. Photo examples load images on demand. The `Stepper`
card uses the navigation category’s artwork style.
